# AprovUp

Sistema para agencias organizarem aprovacao de conteudo, producao, calendario editorial, design, filmmaker e relacionamento com clientes em um so lugar.

## Visao geral

O AprovUp foi criado para simplificar o fluxo de producao de conteudo entre agencia e cliente.

Com ele, a agencia consegue:

- Planejar conteudos por cliente
- Enviar calendario para aprovacao
- Separar demandas de Social Media, Design e Filmmaker
- Acompanhar status de producao
- Enviar material final para aprovacao
- Captar leads pelo site comercial

## Tecnologias

- Next.js
- TypeScript
- Prisma
- Tailwind CSS
